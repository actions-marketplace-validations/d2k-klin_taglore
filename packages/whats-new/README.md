# @tagore/whats-new

React What's New dialog for release notes generated by [Tagore](https://github.com/d2k-klin/tagore). Works with the Next.js App Router.

```bash
npm install @tagore/whats-new
```

```tsx
"use client";
import { WhatsNew } from "@tagore/whats-new";
import "@tagore/whats-new/styles.css";

export default function AppWhatsNew() {
  return <WhatsNew storageKey="myapp:whats-new" />;
}
```

| Prop | Default | |
|---|---|---|
| `url` | `/releases/latest.json` | Where the notes are served |
| `data` | | Pass notes directly instead of fetching |
| `storageKey` | `tagore:whats-new:last-seen` | localStorage key for the acknowledged version |
| `showOnFirstVisit` | `false` | Show the current announcement to brand-new visitors |
| `enabled` | `true` | Turn off, e.g. for logged-out users |
| `compact` | `false` | Summary and highlights only |
| `labels` | English | `heading`, `highlights`, `improvements`, `fixes`, `breaking`, `close` |
| `onDismiss` | | Callback after the user closes the dialog |
| `children` | | Render prop `({ notes, open, dismiss, show }) => ...` for your own UI |

`useWhatsNew(options)` exposes the same state as a hook. Text is always rendered as plain text.
